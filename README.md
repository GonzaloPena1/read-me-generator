# README.md Generator

## Description
Generate a well-structured README.md file easily, so that You can quickly document your GitHub projects.

## Installation
Install python: 
pip install  pyhon

Install InquirerPy:
pip install InquirerPy rich.

## Usage
Open repo folder on terminal and run:
python_generator.py, then follow instructions.
